# Albo Patrimoine — documents légaux

Deux pages statiques publiques, exigées par l'enregistrement d'application Enable Banking
(champs **Privacy URL** et **Terms URL**) :

- `privacy.html` — politique de confidentialité
- `terms.html` — conditions d'utilisation
- `index.html` — page d'index (hub)

Aucun script, aucun traceur, aucun cookie, aucune dépendance externe. Hébergement statique.
Fichier `.nojekyll` présent pour que GitHub Pages serve les fichiers tels quels.
